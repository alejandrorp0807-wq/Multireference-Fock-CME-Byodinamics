# Multireference Fock-Space Representations for Stochastic Biochemical Reaction Networks

**A numerical study of positive probability representations, modal coupling, and model reduction for the chemical master equation**

**Author:** Alejandro Rodríguez Peláez  
**Date:** November 2026  
**Status:** Exploratory numerical research; not a peer-reviewed publication.

## Overview

High-dimensional stochastic reaction networks are difficult to simulate because the number of possible molecular occupation states grows exponentially with the number of species. This project investigates whether a **multireference Fock-inspired modal representation** can approximate their time-dependent joint probability distributions using relatively few coefficients.

The approach combines:

- A chemical master equation (CME) with a generator derived from reaction propensities.
- Several displaced, binomial-product reference distributions rather than one fixed expansion center.
- Orthogonal modal corrections around those reference distributions, including cross-species interactions.
- A **squared-amplitude probability ansatz** that guarantees nonnegative, normalized reconstructed probabilities.
- Numerical comparisons with mean-field closures, exponential-family approximations, Markovian mixtures, finite-state projection controls, and dynamical low-rank (DLR) methods.

The objective is **not** to claim that writing a CME in Fock space automatically reduces its computational complexity. The question is whether a suitable multireference representation can compress distributions generated by nonlinear, correlated reaction networks.

## Mathematical formulation

For an occupation state $\mathbf n=(n_1,\ldots,n_d)$, reaction $r$ has stoichiometric increment $\boldsymbol\nu_r$ and propensity $a_r(\mathbf n)$. The CME is

$$
\frac{dP(\mathbf n,t)}{dt}
=\sum_r\left[
 a_r(\mathbf n-\boldsymbol\nu_r)P(\mathbf n-\boldsymbol\nu_r,t)
 -a_r(\mathbf n)P(\mathbf n,t)
\right],
$$

or, in matrix form, $\dot{\mathbf p}=Q\mathbf p$. The study uses a Fock-space occupation representation to describe how creation, destruction, and nonlinear reaction propensities couple modal orders.

### Positive multireference ansatz

The central approximation represents a real-valued amplitude as

$$
\Psi_{\mathbf n}(t)=\sum_{\alpha=1}^{K}B_{\mathbf n\alpha}c_\alpha(t),
\qquad
P_{\mathbf n}(t)=\frac{\Psi_{\mathbf n}(t)^2}
{\sum_{\mathbf m}\Psi_{\mathbf m}(t)^2}.
$$

Thus, wherever the denominator is nonzero, $P_{\mathbf n}\geq 0$ and $\sum_{\mathbf n}P_{\mathbf n}=1$ by construction. **This guarantees positivity of the reconstructed distribution, not exactness of the projected dynamics.**

The basis $B$ is assembled from orthogonal polynomial modes around multiple product-binomial reference distributions, with their centers estimated from mean-field trajectories. Those centers depend on the reaction model and initial conditions, **not** on the exact future reference solution.

For nonzero amplitudes, the exact CME formally implies $\dot\Psi_{\mathbf n}=(Q\Psi^2)_{\mathbf n}/(2\Psi_{\mathbf n})$ under a normalized amplitude convention. The reduced implementation projects and regularizes this expression; it is consequently an approximation to the full CME.

## Numerical benchmarks

Five synthetic reaction networks were tested, ranging from **2,401 to 279,936 microstates**. Errors below are mean $L^1$ distances between the reconstructed and reference **joint probability distributions** at four times after the initial condition (lower is better).

| Reaction network | Species | Microstates | Best tested Fock modes | Fock $L^1$ | DLR rank 2 $L^1$ | DLR rank 4 $L^1$ |
|---|---:|---:|---:|---:|---:|---:|
| Independent control | 4 | 2,401 | 14 | 0.00003 | 0.00004 | 0.00004 |
| Weakly coupled | 4 | 2,401 | 86 | 0.00196 | 0.0103 | 0.00019 |
| Bistable | 5 | 7,776 | 400 | **0.0326** | 0.0652 | 0.0162 |
| Regulatory cascade | 6 | 46,656 | 360 | **0.0394** | 0.0681 | 0.00955 |
| Strongly coupled | 7 | 279,936 | 215 | 0.0807 | 0.0731 | 0.0200 |

A more compact cascade representation using **245 Fock modes** also attained $L^1=0.0476$. The full report includes additional modal-order sweeps, error-of-event measurements, joint marginal comparisons, and sensitivity studies.

### What these results show

- **Representational promise:** in the bistable and cascade examples, the tested multireference ansatz attained lower error than rank-2 DLR while using fewer representation coefficients.
- **Positivity:** the squared-amplitude reconstruction remains a valid probability distribution without clipping negative entries after the fact.
- **No overall accuracy lead:** rank-4 DLR outperformed the tested Fock configuration on every nontrivial coupled benchmark.
- **No speedup demonstrated:** the current Fock implementation evaluates full-state-space quantities such as $Q(\Psi^2)$, so representation compression has **not** yet translated into a scalable solver.

For example, on the seven-species case, the reported timings were approximately **4.62 s** for the 215-mode Fock method, **0.135 s** for rank-2 DLR, and **0.465 s** for direct Krylov propagation of the CME, under the specific benchmark conditions. These are indicative single-environment timings, not hardware-independent performance claims.

## Main limitations

1. **Scalability:** the current modal evolution and Gram-matrix construction still touch the full state space.
2. **Approximate dynamics:** the regularized, projected squared-amplitude evolution is not identical to the exact CME.
3. **Mode selection:** enlarging a non-nested, truncated basis can worsen accuracy; an adaptive nested basis remains an open task.
4. **Benchmark scope:** the networks are synthetic. The study does **not** validate the method on experimental biological measurements.
5. **State of the art:** stronger tensor-network and hierarchical DLR solvers exist, and are not exhaustively benchmarked here.
6. **Originality:** Fock occupation methods, Doi–Peliti operators, Mori–Zwanzig memory, coherent-state ideas, and low-rank approximations have prior literature. The specific combination tested here is exploratory; novelty or superiority over all previous work has **not** been established.

## Reproducing the experiments

The report documents the following Python entry points. **The Python source files and the requirements file must be uploaded to this repository before these commands can be run.** They are not embedded in this README.

```bash
python -m pip install -r requirements.txt

# Baseline cases (4, 5, 6, and 7 species)
OPENBLAS_NUM_THREADS=1 python experiment.py --case 4
OPENBLAS_NUM_THREADS=1 python experiment.py --case 5
OPENBLAS_NUM_THREADS=1 python experiment.py --case 6
OPENBLAS_NUM_THREADS=1 python experiment.py --case 7

# Extended multireference studies
OPENBLAS_NUM_THREADS=1 python extended.py --case 5
OPENBLAS_NUM_THREADS=1 python extended.py --case 6
OPENBLAS_NUM_THREADS=1 python extended.py --case 7

# Controls and plots
OPENBLAS_NUM_THREADS=1 python fsp_control.py
OPENBLAS_NUM_THREADS=1 python aggregate_figures.py
```

On **Windows PowerShell**, set the thread limit before running the same scripts:

```powershell
$env:OPENBLAS_NUM_THREADS = "1"
python experiment.py --case 5
```

The original study used Python/SciPy computations with single-threaded BLAS for indicative timing comparisons. See the report for the full protocol, regularization sensitivity checks, audit of the CME generator, and the stated limitations of individual experiments.

## Next research steps

A meaningful continuation would require (i) a local or tensorized evaluation of modal contractions without allocating the full probability vector, (ii) nested or adaptive basis selection, and (iii) benchmarks on larger reaction networks against modern tensor-based DLR methods at matched error tolerances and measured end-to-end cost.
